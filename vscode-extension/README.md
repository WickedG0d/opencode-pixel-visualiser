# OpenCode & Antigravity Pixel Visualizer for VS Code

Visualize your multi-agent workflows in a real-time pixel-art office scene directly inside Visual Studio Code.

## Features
- **Live Parallel Office Scene**: Watch up to 5 AI agents typing at their desks, walking to coffee, and executing tasks simultaneously.
- **Floating Task Bubbles**: See each agent's active tool and task in real time.
- **One-Click Launch**: Click `$(symbol-event) Pixel Visualizer` in the VS Code status bar.
- **Editor or Sidebar**: View the office scene beside your code or in the VS Code side panel.
- **Built-in Orchestrator**: Run 5 specialized engineering agents in parallel with one click.

## Usage in VS Code
1. Start the visualizer server (`npm start` or Run Task: **Start Visualizer Server**).
2. Click **Pixel Visualizer** in the bottom status bar, or run command `OpenCode Visualizer: Open Office in Editor`.
3. To run parallel agents, click `⚡ Run 5 Parallel Agents` in the visualizer HUD or run task **Run Parallel Orchestrator (5 Agents)**.
